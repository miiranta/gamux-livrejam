# Creditos dos assets do personagem

Sprites montados a partir do **Universal LPC Spritesheet Character Generator** (Liberated Pixel Cup), camada por camada.

- Repositorio das camadas: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

## Licenca da obra derivada

Cada camada esta disponivel sob mais de uma licenca. As licencas comuns a **todas** as camadas usadas aqui sao:

- **CC-BY-SA 3.0**
- **GPL 3.0**

Ou seja, o personagem montado (e qualquer edicao dele) deve ser distribuido sob **CC-BY-SA 3.0** ou **GPL 3.0**. As camadas que restringem o conjunto (as unicas sem opcao OGA-BY) sao: `body/wound/arm`, `body/wound/brain`, `body/wound/eye_left`, `body/wound/eye_right`, `body/wound/mouth`, `body/wound/ribs`, `hair/bedhead` — as feridas vem do [LPC] Zombie. Trocando o cabelo por um com OGA-BY e tirando as feridas, o resto do personagem poderia ser usado so com credito, sem share-alike.

O que isso exige na pratica:

1. Creditar os autores listados abaixo (uma tela de creditos no jogo, o README ou a pagina do jogo na jam servem).
2. Distribuir os arquivos de arte modificados sob a mesma licenca (share-alike).
3. O **codigo do jogo nao e afetado** se voce escolher CC-BY-SA 3.0 para a arte. Escolher GPL 3.0 para a arte e que traria obrigacoes de codigo — nao precisa.
